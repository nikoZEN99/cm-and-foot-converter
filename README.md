# CM ↔ Foot Converter

A simple desktop GUI app built with Python and tkinter that converts between centimeters and feet.

## Features

- Convert cm → feet
- Convert feet → cm
- Input validation (warns if both or neither field is filled)
- Clears input fields automatically after each conversion

## Requirements

- Python 3

No external libraries needed — this uses tkinter, which ships with standard Python installs.

## Usage

```bash
python "height converter.py"
```

Enter a value in either the **cm** or **foot** field (not both), then click **Convert**.
